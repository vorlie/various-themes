# Various Themes

A collection of custom CSS themes and UI customizations I've made for various applications and services.

The themes are primarily designed for use with **Stylus**, but some may work with other CSS injection methods depending on the application.

## 🎨 Themes

### Plex

**Catppuccin Mocha**

A Catppuccin Mocha customization for Plex Web, built on top of the [Theme-Park Plex base theme](https://theme-park.dev/css/base/plex/plex-base.css).

Features:

* Catppuccin Mocha color palette
* Mauve primary accent
* Green playback and progress indicators
* Customized buttons, badges, tooltips, and dropdowns
* Improved hover and selection states
* Catppuccin-styled navigation and sidebar
* Darker translucent UI elements
* Improved contrast throughout the interface

[View Plex theme →](./plex/)

Each theme may include its own README with installation instructions, dependencies, attribution, and additional information.

## 🧩 Usage

Most themes in this repository are intended to be used with [Stylus](https://add0n.com/stylus.html).

Installation instructions may vary between themes, so check the README inside the corresponding theme directory.

## ⚠️ Compatibility

These themes modify third-party applications and websites using CSS selectors that may change when the application is updated.

A theme may therefore require maintenance after an upstream UI update.
